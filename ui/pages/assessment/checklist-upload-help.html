Excel Checklist Upload

Complete a department checklist offline and submit it safely.

Steps

  1. Select the activated Department.
  2. Click Download Sample Excel. Do not edit Metadata or checkpoint columns.
  3. Enter only 0, 1, or 2 in the yellow Compliance column.
  4. Upload the workbook. SaQshi validates metadata, checkpoint IDs, duplicates and compliance values.
  5. Review the full table, grouped by Area of Concern, then select Final Submit.

Compliance

  • 0 Non-compliant
  • 1 Partially compliant
  • 2 Fully compliant

Resume

SaQshi saves in batches. If logout, browser closure, or connectivity interruption occurs, return to Upload via Excel and select the same department. Use Resume Submit; no file upload is needed again.

After completion

Continue with Gap Analysis, Action Plan, and Gap Closure.

Delete Uploaded Excel is blocked once an Action Plan exists or Gap Closure is completed.
