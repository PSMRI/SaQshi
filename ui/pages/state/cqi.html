How these values are counted
Only each facility's latest completed checklist is included. Facilities Requiring Action Plan means its checklist has at least one 0/1 checkpoint and therefore needs an action plan. Created but Not Closed means a plan exists but one or more plans are not yet closed. All Created and Closed means every created plan is marked Closed. Not Started means an action plan is needed but none was created. Requiring Action Plan = Created but Not Closed + All Created and Closed + Not Started.
