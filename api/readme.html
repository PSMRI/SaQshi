SaQshi APIs v1

1. Overview

SaQshi provides open, stateless, JSON-based APIs for healthcare quality assessment, facility master data, and certification lifecycle management.

  • Assessment checklist retrieval & compliance submission
  • Assessment resume & progress tracking
  • Facility master hierarchy (State → Division → District → Block → Facility)
  • Certification create, update, verification & analytics
  • Dashboard-ready aggregated analytics

Designed for Government Systems, Mobile Apps, Dashboards and Digital Public Goods (DPG).

4. Authentication

APIs are currently open for integration.

API Key / Token / OAuth2 authentication can be added later without breaking existing contracts.

5. Recommended Assessment API Flow

  1. Get Areas of Concern
  2. Get Sub-Standards
  3. Get Checklist Items
  4. Save Compliance Response
  5. Track Progress
  6. Resume Assessment

6. Assessment APIs

Get Areas of Concern

GET /assessment/v1/concerns 
?facility_type=3&department_id=2

Get Sub-Standards

GET /assessment/v1/standards

Get Checklist Items

GET /assessment/v1/checklist

7. Assessment Response APIs

Save Response

POST /assessment/v1/response/save 
{
  "csqa_id": 123,
  "compliance": 2,
  "facility_id": 1,
  "department_id": 2,
  "assessment_period": 2024
}

Resume Assessment

GET /assessment/v1/response/resume

Get Progress

GET /assessment/v1/response/progress

8. Facility Master APIs

Hierarchy APIs

GET /facility/v1/masters/states
GET /facility/v1/masters/divisions?state_id=10
GET /facility/v1/masters/districts?division_id=101
GET /facility/v1/masters/blocks?district_id=2201

Facility CRUD

GET  /facility/v1/masters/facilities/get.php
POST /facility/v1/masters/facilities/create.php
PUT  /facility/v1/masters/facilities/update.php?facility_id=1

9. Certification APIs

Create Certification

POST /certification/v1/data/create.php

Update Certification

PUT /certification/v1/data/update.php?fac_nin=2711231247

Get Certification Records

GET /certification/v1/data/get.php

Public Verification

GET /certification/v1/verification/public.php?fac_nin=2711231247

Certification Analytics

/analytics.php?type=district_leaderboard
/analytics.php?type=cert_type_summary&mode=history

10. Certification Rules (Calculated)

  • Certified → Valid for 3 years
  • Conditional → Valid for 1 year

Expiry dates are calculated dynamically and never stored in the database.
